# UI review screenshots

Put screenshots for the UI review here.

- Name: `NN-page-issue.png`, for example `01-home-kpi-badge-missing.png`, `07-matrix-header-cramped.png`. `NN` is the order you found them.
- For every image, add a note in `NOTES.md`:

```
## 07-matrix-header-cramped.png
Page: /matrix.html
What I see: header text wraps into two lines at 1280 px
What I expect: one line
Question or fix: fix
```

Notes can be a fix request or a question. Each one gets a before and after screenshot back.
