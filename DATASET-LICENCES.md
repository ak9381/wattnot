schema-ingest is confidential and is not part of any set below. No dataset file mentions it. Two docs only name it as a rule ("never use it"): `docs/handoff/01-rules.md` and `docs/runbooks/META-USAGE.md`. Leave those two out of any public data bundle.

## Open questions for Akash

1. **edge-tts audio:** drop it from any public bundle, or regenerate with an openly licensed TTS?
2. **Meta model outputs** (Muse Image images, Spark-generated muse-code-v1, answers in results): Meta's terms for the hackathon models need a final read before we publish them.
3. **`rack/ai/rack.jpg`:** the note says AI-generated but not by which tool. If it was Muse Image, it follows rule 2.
4. **`rack/rack.jpg` (root):** no source is recorded and it doesn't match the Compaq photo file. Find where it came from, or leave it out.
5. **Our own sets:** CC0 for prompts and CC BY 4.0 for results, as proposed on 3 Nov. tiers-v1, prefix-cache-v1, load-prompts and judge-30 have no licence line yet.
6. **Share-alike:** anything drawn on the CC BY-SA photos (SAM masks, audit overlays) must ship under CC BY-SA, not CC0.
