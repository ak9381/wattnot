Checks, in order

    How it works. The receipt is written in canonical JSON (RFC 8785), hashed with SHA-256, and the hash is signed with Ed25519. This page does the same maths, re-derives the grade (the grade written in the receipt is ignored), and recomputes joules from the receipt's own numbers. It is a port of verifier/wattnot_verify.py, tested on the same 9 vectors. Spec v0.1 is an open draft, not a standard.

    Trusted signers

    The sample key is a public test key. Signatures from it prove the checker works, not that a real run happened.
