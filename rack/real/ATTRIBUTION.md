# Rack photo

`rack.jpg` is "Compaq server rack - IMG 0146.jpg" by Jemimus, from Wikimedia
Commons, licensed CC BY 2.0 (https://creativecommons.org/licenses/by/2.0/).
Source: https://commons.wikimedia.org/wiki/File:Compaq_server_rack_-_IMG_0146.jpg
(originally on Flickr). We use the 960 px wide Commons thumbnail, unchanged.

The rack and slot outlines in `masks.manual.json` are ours. The four slots
are server units in the right-hand cabinet, mapped to GPU 0 to 3 for the
demo; these are not real GPU positions. `pdu-1` is the wall power outlet
panel, the closest visible power feed in this photo.
